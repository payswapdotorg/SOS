# SOS — Software Operating System

SOS is a mission-governed operating system for evolving software systems.

The repository is the durable source of truth for the SOS product architecture, frozen roadmap, requirements, implementation process, and evidence of implementation progress.

## Core thesis

Software is not the end product of SOS. A running software system is an evolving realization of a mission.

`Mission → Model → Observe → Hypothesize → Search → Validate → Experiment → Promote/Rollback → Learn → Repeat`

Architecture is a hypothesis. Evidence determines belief. Safety and authority bound autonomy.
